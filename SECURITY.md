# Security Policy

CampusRoute AI is an open-source research and engineering prototype. It is not
a safety-critical robot controller.

Do not publish credentials, personal GPS traces, private campus maps or
security-sensitive details in a public issue. Report vulnerabilities privately
through the repository's GitHub security contact.

Before deployment, use HTTPS, proper authentication, protected administrative
actions, a secure database and an approved privacy policy. Never commit API
keys, passwords, tokens or `.env` files.
